# Real-time Serial Data Plotter

**PyQt5**와 **PyQtGraph**를 기반으로 제작된 실시간 시리얼 데이터 모니터링 및 플로팅 프로그램입니다.
마이크로컨트롤러(Arduino, STM32 등)나 센서로부터 전송되는 시계열 데이터를 실시간으로 그래프로 시각화하고, 로그를 기록하며 CSV 파일로 저장할 수 있습니다.

## 📌 주요 기능 (Features)

### 1. 실시간 데이터 시각화
- **고속 그래프**: `pyqtgraph`를 사용하여 대량의 데이터도 부드럽게 실시간으로 렌더링합니다.
- **다중 채널 지원**: 콤마(`,`)로 구분된 여러 개의 숫자 데이터를 동시에 수신하여 각각 다른 색상의 그래프(채널)로 표시합니다.
- **범례(Legend) 수정**: 그래프 범례를 더블 클릭하여 채널 이름을 변경할 수 있습니다.

### 2. 시리얼 통신 관리
- **포트 스캔**: 현재 사용 가능한 시리얼 포트를 자동으로 검색합니다.
- **설정**: 다양한 Baudrate(통신 속도)를 지원하며, 연결 상태를 LED 인디케이터로 직관적으로 보여줍니다.
- **데이터 송신**: 텍스트 명령어를 입력하여 연결된 장비로 데이터를 전송할 수 있습니다.

### 3. 데이터 저장 및 캡처
- **CSV 저장**: 수신된 데이터를 버퍼링하여 메타데이터(기록 시간, 샘플링 레이트 등)와 함께 CSV 파일로 내보낼 수 있습니다.
- **이미지 캡처**: 현재 그래프 화면을 PNG 또는 JPG 이미지 파일로 즉시 저장할 수 있습니다.

### 4. 사용자 편의 기능
- **그래프 제어**: 
  - X축 범위(윈도우 크기) 조절 슬라이더
  - Y축 자동 스케일링 (Auto Scale) On/Off
  - 선 굵기 조절
  - 그래프 업데이트 일시 정지 (Pause)
- **로그 뷰어**: 수신된 Raw 데이터와 시스템 메시지를 별도의 로그 창에서 확인할 수 있습니다.
- **샘플링 레이트 표시**: 실시간 데이터 수신 속도(Hz)를 계산하여 표시합니다.

## 🛠 요구 사항 (Requirements)

이 프로그램은 Python 3 환경에서 동작하며, 다음의 라이브러리가 필요합니다.

- Python 3.x
- PyQt5
- pyqtgraph
- pyserial

### 설치 (Installation)

필요한 패키지를 `pip`를 통해 설치합니다.

```bash
pip install PyQt5 pyqtgraph pyserial
```

## 🚀 사용 방법 (Usage)

1. **프로그램 실행**:
   ```bash
   python SerialDataPlotter.py
   ```

2. **장치 연결**:
   - 상단 패널에서 장치가 연결된 **Serial Port**를 선택합니다. (목록에 없다면 `Scan` 버튼 클릭)
   - 장치와 맞는 **Baudrate**를 선택합니다.
   - `Connect` 버튼을 누르면 데이터 수신이 시작됩니다.

3. **데이터 형식 (Protocol)**:
   - 송신 측(MCU 등)에서는 데이터를 **콤마(,)**로 구분하고 **줄바꿈(\n)** 문자로 끝나는 문자열을 보내야 합니다.
   - 예시:
     ```text
     1023, 512, 245\n
     ```
     위와 같이 전송 시 3개의 채널로 인식되어 그래프에 그려집니다.

4. **데이터 저장**:
   - `Start Saving` 버튼을 누르면 데이터 기록이 시작됩니다.
   - `Stop Saving` 버튼을 누르면 파일 저장 대화상자가 열리며 CSV 파일로 저장됩니다.
